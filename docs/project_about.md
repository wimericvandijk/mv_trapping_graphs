#

The Marsden Valley Trapping Group runs community trapping activity in Marsden Valley New Zealand and uses this dashboard to publish public trapping trends from Trap.NZ data.
Follow the group on [the Marsden Valley Trapping Group Facebook page](https://www.facebook.com/groups/991610803052734/).

This site focuses on simple views of catch history:

- weekly catches for the selected species and period
- same-species comparison across available years
- summary totals and trend indicators for rolling periods and calendar years

The current dashboard is intended as a public summary view rather than a full operational analysis tool.
